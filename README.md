# B8A1: Problem Solving with TypeScript & OOP

## Assignment Overview
This repository contains my solutions for **Assignment 1**, covering core TypeScript and Object-Oriented Programming (OOP) concepts from Modules 1, 2, and 3:
- Basic types, optional and default parameters (`multiplyValue`)
- Union types and `typeof` type narrowing (`processInput`)
- Readonly tuples (`formatCoordinate`)
- Generics and rest parameters (`concatenateArrays`)
- Interfaces and array filtering (`Course`, `getPopularCourses`)
- Generics with `keyof` constraints (`pluckValues`)
- OOP classes, inheritance, `protected` and `private` access modifiers (`Employee`, `Manager`)
- Asynchronous programming with `Promise`, `setTimeout`, and error handling (`validateAgeAsync`)
